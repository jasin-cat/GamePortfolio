EmpireDash 実装コード

NewKentaフォルダで担当したプレイヤー制御・演出の実装例です。各項目を開くと、スクリプトの抜粋を確認できます。

実装コードを見る：プレイヤーの状態管理

共通のIStateを通して、現在の状態を終了してから次の状態を開始します。物理更新も現在の状態へ委譲します。

// PlayerManger.cs より抜粋（クラス内の一部）
public void ChangePlayerState(IState nextState)
{
    if (nextState == null) return;
    _currentIState.Exit();
    _currentIState = nextState;
    nextState.Enter();
}

public void FixedUpdate()
{
    if (_currentIState != null)
    {
        _currentIState.FixedUpdate();
    }
}
実装コードを見る：入力と物理更新の分離

Updateでジャンプ入力を受け取り、FixedUpdateでRigidbody2Dの速度を変更します。ポーズ中は入力・移動処理を止めます。

// Admission.cs より抜粋（クラス内の一部）
public void Update()
{//地面に当たったら2段ジャンプのカウントを戻す・ジャンプを可能にする
    if(!_isThisMovement || PauseController.IsPause) return;
    if (_player.OnGround)
    {
        _count = 1;
    }

    if (Input.GetKeyDown(KeyCode.Space) && _count < _maxCount)
    {
        _player.SelectAudio.JmupSE();
        _isMove = true;
    }
}

public void FixedUpdate()
{// ジャンプを行う2段ジャンプのカウントを1増やす
    if(PauseController.IsPause) return;
    if (!_isMove) return;

    this._movementRigid.velocity = Vector3.up * _speed;
    _count++; // インクリメントを前につけないと3段ジャンプが可能になる

    _isMove = false;
}
実装コードを見る：重力反転と状態終了時の復元

入力に応じて重力とキャラクターの向きを切り替えます。状態を抜ける際に重力・縦速度・回転を戻します。

// SD.cs より抜粋（クラス内の一部）
public void FixedUpdate()
{
    if(PauseController.IsPause) return;  
    if(_isMove)
    {
        _player.SelectAudio.JmupSE();
        float targetRot;
        if(_movementRigid.gravityScale == _gravity)
        {
            _movementRigid.gravityScale = _reverseGravity;
            targetRot = 180.0f;
        }
        else
        {
            _movementRigid.gravityScale = _gravity;
            targetRot = 0;
        }

        if(_movementRigid.gravityScale > 0) 
            _addForceGravity = -Mathf.Abs(_addForceGravity);
        else
            _addForceGravity = Mathf.Abs(_addForceGravity);

        _movementRigid.velocity = new Vector2(_movementRigid.velocity.x, _addForceGravity);
            
            _player.transform.rotation = Quaternion.Euler(targetRot, 0, 0);
        _isMove = false;
    }
}

public void Exit()
{
    if(!_isThisMovement) return;
    _movementRigid.gravityScale = _gravity;
    _movementRigid.velocity = new Vector2(_movementRigid.velocity.x, 0);
    _player.transform.rotation = Quaternion.Euler(0, 0, 0);
    _isThisMovement = false;
}
実装コードを見る：フェードとシーン切り替えの連携

フェードで画面を覆ってから渡された非同期処理を実行し、完了後に画面を戻します。処理中はUIへの入力を遮断します。

// NewKenta/FadeController.cs より抜粋
public async UniTask Fade(Func<UniTask> uni)
{
    image.raycastTarget = true;
    image.transform.SetAsLastSibling();

    await this.image.DOFade(1, 1f).AsyncWaitForCompletion();

    this.image.transform.SetAsLastSibling();

    if(uni != null) await uni();

    await UniTask.Yield(PlayerLoopTiming.Update);

    await this.image.DOFade(0, 0.25f).AsyncWaitForCompletion();

    this.image.transform.SetAsFirstSibling();

    image.raycastTarget = false;
}
